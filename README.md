# 02225 Distributed Real-Time Systems

This repository contains the work done for the Distributed Real-Time Systems course taught in DTU (Technical University of Denmark) in the 2025 Spring Semester. 

At a first stage, as a preparation/introduction for the final project, a simple simulator and an analysis tool were developed to better understand real-time task scheduling for a system. How to conduct an analysis for a set of tasks and their schedulability, the differences between a theoretical analysis and a more practical approach and how to consider these results. This can be found in the **Exercise Hand-In** folder.

After this exercise was concluded, the final project was developed. It also consisted of a simulator and an analysis tool, like in the previous exercise, but with a more complex approach, on a multicore system that followed a Hierarchical scheduling policy. This can be found in the **project** folder.

Both folders contain their own README file, which gives out more details about the goals and features of each, along with how to run them.
